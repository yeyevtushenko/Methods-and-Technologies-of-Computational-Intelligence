# Практична робота №1: Основи роботи в Python

Репозиторій містить розв'язання завдань практичної роботи №1.

## Файли

- `lab1.py` — розв'язання пунктів a)–w) практичної частини. Блоки, розділені `# %%`, можна вставляти як окремі комірки в Google Colab.

## Як запустити в Google Colab

1. Відкрийте https://colab.research.google.com і створіть новий блокнот.
2. Вставте вміст `lab1.py` у комірки (кожен блок `# %%` — окрема комірка) і запустіть їх.

## Примітки

- Пункт m) у завданні названо "об'єднання", а в дужках — "intersection". У коді виведено обидві операції.
- Пункт 2 практичної частини (короткий опис використання для варіанту) та висновки виконуються окремо у звіті.
